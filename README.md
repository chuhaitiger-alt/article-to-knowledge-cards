# 文章转知识卡片

这是一个 Codex Skill：`article-to-knowledge-cards`。它指导 Codex 将用户提供的文章、可读取的网页或文档整理成知识卡片。项目不包含独立的转换程序或网页应用。

## 解决什么问题

长文章适合连续阅读，却不方便回顾单个概念；将段落直接缩短成摘要，也容易丢失论点的前提、例外和出处。本 Skill 帮助把值得记住的知识点拆成独立可读的卡片，并保留回查原文的位置。

## 主要功能

- 提取文章的关键概念、论点、机制和适用边界，合并重复内容，不按段落机械拆分。
- 默认以用户使用的语言生成 Markdown 文字卡片；每张包含标题、核心知识、解释、必要的适用条件或例外，以及原文来源位置。
- 按用户要求调整语言、读者、卡片数量和格式，例如问答卡、Anki 字段或表格。
- 区分原文中的事实、作者解释与推测；只读到节选时说明覆盖范围，不凭标题补写正文。

Skill 会转换输入内容，**不会自动核实文章引用的书籍、案例或外部链接**。若需要事实核查，应在使用时单独提出。

## 安装方法

需要能够使用 Skills 的 Codex。此 Skill 只有一个 `SKILL.md` 文件，无需安装 Python 包或运行服务。

在项目根目录执行：

```sh
SKILL_DIR="${CODEX_HOME:-$HOME/.codex}/skills/article-to-knowledge-cards"
mkdir -p "$SKILL_DIR"
cp skills/article-to-knowledge-cards/SKILL.md "$SKILL_DIR/SKILL.md"
```

项目中的源文件是 [`skills/article-to-knowledge-cards/SKILL.md`](skills/article-to-knowledge-cards/SKILL.md)。复制后即可在支持 Skills 的 Codex 会话中调用 `$article-to-knowledge-cards`。

## 使用方法

在 Codex 对话中提供文章正文，或提供 Codex 能读取的文件、网页链接，再说明要生成知识卡片：

```text
使用 $article-to-knowledge-cards，把下面的文章转成知识卡片：

[粘贴文章正文]
```

也可以指定结果，例如“面向初学者，生成 8 张问答卡”或“将卡片保存到项目根目录的 Markdown 文件”。默认输出为对话中的 Markdown 卡片；保存到文件需在请求中说明。

## 输入输出示例

以下片段取自本项目示例所依据的用户提供文章：

**输入**

```text
归纳法是观察大量现象，然后总结规律。它隐含一个假设：未来和过去具有连续性。过去成立，不等于永远成立。
```

**输出示意**

```markdown
### 1. 归纳经验依赖环境连续性
**核心知识：** 从过去的重复现象推测未来，隐含了环境具有连续性的前提。
**解释：** 归纳法能帮助发现规律，但支撑规律的条件变化时，过去有效的模式可能失效。
**适用/边界：** 使用历史经验时，先检查原有条件是否仍然存在；这不意味着经验本身没有价值。
**来源：** 用户提供的解读文章 · 第二节「为什么作者先花很多篇幅讲归纳法」。
```

项目根目录中的 [`第一性原理-知识卡片.md`](第一性原理-知识卡片.md) 是一次完整输出示例，共 16 张卡片。它依据用户提供的《第一性原理》解读文章整理，未与原书逐页核对；原始输入文章未收录在项目中。
